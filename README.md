# RØK Performance – email assets

Repo `rok-email-asset`. Images for the RØK email signature, served by GitHub Pages at `https://assets.rokperformance.com/`.
They're hosted here, not on rokperformance.com, because SiteGround's anti-bot check blocks image requests from email apps.

Do not rename or delete these files: signatures already sent point at them. To change an image, upload a new file with a new name and update the signature.
